# cybOS v0.7.2

Hardened macOS release built from c1cad4/CybOS-demo release/v0.7.2 at commit 9fe5461118d41fa3eee54dc79882bbb739968af5.

Includes:
- universal Apple Silicon + Intel packaging;
- bounded Qwen input;
- SQLite/WAL persistence hardening;
- cached database diagnostics;
- secure-message replay protection;
- Noise XX end-to-end delivery/ACK and application-level acceptance/rejection;
- SHA-256 checksum published with the release asset.
