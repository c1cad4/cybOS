# Новые компоненты и границы

Найдено 18 новых публичных репозиториев среди 39 доступных репозиториев аккаунта. При первичной проверке у каждого были только README.md и LICENSE. Теперь пять проектов реализуют рабочую вертикаль агенты → координация → память → HTTP API.

## Предлагаемые границы ответственности

| Слой | Репозитории | Граница |
|---|---|---|
| Инфраструктура | CybCore | API и координация серверных сервисов; существующий robotcyb-core остаётся библиотекой worker/hardware контрактов. |
| Агенты | CybMind, CybAgents, CybSwarm, CybRegistry | Mind — сборка интеллектуальной подсистемы; Agents — отдельный агент; Swarm — координация; Registry — учёт возможностей и версий. |
| Память | CybBrain, CybMemory | Brain — сборка памяти/обучения; Memory — хранилище и поиск; существующий soul — общие типы данных. |
| Безопасность | CybShield, CybIdentity, CybTrust | Shield — сборка политики безопасности; Identity — ключи и идентичность; Trust — проверяемые свидетельства репутации. cybguard проверяет действия, immunocybchain — повторы сообщений. |
| Физический мир | CybRobot, CybWorld | Robot — адаптеры и безопасное управление; World — модель объектов и наблюдений. cybbee хранит отдельные бионаблюдения. |
| Обучение людей | CybGrowth, CybMentor, CybMissions | Growth — общий пользовательский сценарий; Mentor — наставник; Missions — задания и подтверждения. |
| Блокчейн интерфейсы | CybWallet, CybExplorer | Wallet — тестовая подпись и транзакции; Explorer — чтение блоков и транзакций существующего узла go-cyber. |
| Эксперименты | CybLab | Песочница с явными границами экспериментального кода. |

Это предложение архитектуры по описаниям владельца, а не обнаруженные программные зависимости. Все 18 проектов включены в каталог. Реализованы CybCore, CybAgents, CybRegistry, CybMemory, CybSwarm; остальные 13 имеют статус planned. Предлагаемые границы таблицы не означают реализованные программные зависимости.
